# 🍕 OMG Pizza

Sitio web oficial de **OMG Pizza** — El sabor que te hará decir OMG!

## ✨ Características

- Diseño responsive con paleta corporativa (rojo, verde, dorado, crema)
- Menú dinámico por categorías (Especialidades, Bebidas, Side Orders)
- Constructor interactivo **"Arma tu pizza"** con pizza visual en capas (CSS puro)
- Envío directo de pedidos por WhatsApp
- Banner multilingüe rotativo (ES/EN/IT/PT/FR)
- Panel de administración con login y exportar/importar catálogo en JSON
- Sin dependencias de build — vanilla HTML5 + CSS + JavaScript
